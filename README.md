# Αναγνώριση ασθενειών σε φύλλα καλλιεργειών 

Συμμετοχή στον 8o Πανελλήνιο Διαγωνισμό Ανοιχτών Τεχνολογιών στην Εκπαίδευση

Προωθούμε την βιώσιμη ανάπτυξη χρησιμοποιώντας την Τεχνητή Νοημοσύνη

ΣΧΕΔΙΑΣΜΟΣ:  
1) Δημιουργήσαμε μια μακέτα όπου υπάρχουν οι καλλιέργειες της ελιάς και του καλαμποκιού.
2) Πάνω στη μακέτα τοποθετούμε μια διάταξη κύλισης (slider).
3) Πάνω στην πλατφόρμα έχουμε τοποθετήσει μια  κάμερα esp32cam η οποία «σκανάρει» όλη την καλλιέργεια.
4) Χρησιμοποιήσαμε το εργαλείο teachable machine της Google για να δημιουργήσουμε - εκπαιδευσουμε το μοντέλο μας.
5) Μέσου ενός απλού αρχείου html (index.html) δημιουργείτε τοπικά μια ιστοσελίδα στην οποία τρέχει ο έτοιμος κώδικας σε JavaScript που μας παρέχει το teachable  machine.
    
ΛΕΙΤΟΥΡΓΙΑ: 
1) Τοποθετούμε την κάμερα πάνω στην πλατφόρμα.
2) Τρέχουμε το αρχείο index.html και σιγουρευόμαστε ότι η κάμερα δουλεύει και στέλνει την εικόνα στην ιστοσελίδα.
3) Συνδέουμε την τροφοδοσία τόσο στον μηχανισμό όσο και στο arduino uno.
4) Η πλατφόρμα αρχίζει να κινείτε. Σε συγκεκριμένες θέσεις σταματά για να κάνει αναγνώριση των φύλλων. Παραμένει στη θέση ανίχνευσης για 2 δευτερόλεπτα.
5) Η εικόνα ελέγχεται από τον υπολογιστή μας. Παρέχεται το είδος της ασθένειας καθώς και το ποσοστό αναγνώρισης.
