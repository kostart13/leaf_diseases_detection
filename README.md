# Αναγνώριση ασθενειών σε φύλλα καλλιεργειών 

Η τεχνητή νοημοσύνη εμπεριέχεται σε όλο και περισσότερους τομείς της ζωής μας. 
Την εκπαίδευση, την υγεία, την ενέργεια ακόμη και στον πρωτογενή τομέα και πιο συγκεκριμένα στην γεωργία.
Θα χρησιμοποιήσουμε την τεχνητή νοημοσύνη και πιο συγκεκριμένα τη μηχανική μάθηση (machine learning) για να εκπαιδεύσουμε ένα σύστημα (μοντέλο) που  θα ανιχνεύει αρρώστιες των καλλιεργειών.
Πιο συγκεκριμένα θα ασχοληθούμε με την Ελιά και το Καλαμπόκι.
Μετά από έρευνα που κάναμε ανακαλύψαμε ότι οι περισσότερες ασθένειες των δέντρων συνδέονται με την υγεία των φύλλων τους. Οπότε θα ασχοληθούμε με αρρώστιες των φύλλων.
Το project μας θα αποτελείται από τα παρακάτω τμήματα:
1)	Μια μακέτα όπου θα υπάρχουν οι καλλιέργειες καθώς και διάφορα φύλλα, υγιή ή ασθενή.
2)	Πάνω στη μακέτα θα υπάρχει μια διάταξη κύλισης (slider) που θα μετακινεί μια κάμερα esp32cam η οποία θα «σκανάρει» όλη την καλλιέργεια.
3)	Η κάμερα θα έχει προγραμματιστεί μέσω Arduino IDE ώστε να λειτουργεί ως web server και να στέλνει μέσω wifi την εικόνα σε ip address που θα γνωρίζουμε.
4)	Θα εκπαιδεύσουμε μέσω του εργαλείου teachable machine το μοντέλο μας ώστε να αναγνωρίζει τα υγιή και άρρωστα φύλα καθώς και τη συγκεκριμένη ασθένεια στην δεύτερη περίπτωση. 
5)	Θα χρησιμοποιήσουμε τον online editor p5js που θα χρησιμοποιεί το ip address της κάμερας, το εξωτερικό link του μοντέλου μας που παρέχει το teachable machine καθώς και τον έτοιμο κώδικα σε javascript που μας παρέχει επίσης το teachable  machine ώστε να έχουμε στην οθόνη του υπολογιστή μας την εικόνα της κάμερας καθώς και την αναγνώριση (και με ποσοστό) υγιούς ή ασθενούς φύλλου.

Λίστα εξοπλισμού:
1 arduino uno
1 nema17 stepper motor + βάση
1 L298N module
4 βασεις στήριζης
2 άξονες ολίσθησης
1 ιμάντας κύλισης + 2 τροχαλίες χροβισμού (pulley)
1 esp32 cam
1 βάση για την κάμερα (3d printed)
Καλώδια – breadboard - μπαταρίες 9V.
