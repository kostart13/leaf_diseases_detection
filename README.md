# Αναγνώριση ασθενειών σε φύλλα καλλιεργειών 

Συμμετοχή στον 8o Πανελλήνιο Διαγωνισμό Ανοιχτών Τεχνολογιών στην Εκπαίδευση

Προωθούμε την βιώσιμη ανάπτυξη χρησιμοποιώντας την Τεχνητή Νοημοσύνη

ΣΧΕΔΙΑΣΜΟΣ:  
1) Δημιουργήσαμε μια μακέτα όπου υπάρχουν οι καλλιέργειες της ελιάς και του καλαμποκιού.
2) Πάνω στη μακέτα τοποθετούμε μια διάταξη κύλισης (slider).
3) Πάνω στην πλατφόρμα έχουμε τοποθετήσει μια  κάμερα esp32cam η οποία «σκανάρει» όλη την καλλιέργεια.
4) Χρησιμοποιήσαμε το εργαλείο teachable machine της Google για να δημιουργήσουμε - εκπαιδευσουμε το μοντέλο μας.
5) Μέσου ενός απλού αρχείου html (index.html) δημιουργείτε τοπικά μια ιστοσελίδα στην οποία τρέχει ο έτοιμος κώδικας σε JavaScript που μας παρέχει το teachable  machine.
   

ΥΛΟΠΟΙΗΣΗ: Δημιουργήσουμε μια μακέτα παιδικής χαράς. Στο βάθος του χώρου υπάρχει η έξυπνη τουαλέτα. Εκτυπώσαμε σε 3d printer όλα τα απαραίτητα στοιχεία του χώρου, λειτουργικά (τουαλέτα) αλλά και διακοσμητικά (νιπτήρας, τσουλήθρα, παγκάκια κτλ.) 
ΛΕΙΤΟΥΡΓΙΑ: Υπάρχει μια ευχάριστη οθόνη lcd που ενημερώνει το παιδί αν η τουαλέτα είναι διαθέσιμη. Μόλις το παιδί περάσει την πόρτα ένας αισθητήρας απόστασης θα ενημερώσει το Arduino Uno ώστε να ανάψει τα φώτα, να ξεκινήσει ευχάριστη μουσική από ένα mini-mp3 player και να αλλάξει τη διαθεσιμότητα σε κατειλημμένη. Όταν το παιδί τελειώσει, ένας άλλος αισθητήρας απόστασης θα ανιχνεύσει την κίνηση του χεριού του και χωρίς επαφή θα ενεργοποιήσει μια αντλία νερού που θα καθαρίσει την τουαλέτα. Στον χώρο υπάρχει και αισθητήρας θερμότητας που σε συνεργασία με ένα mini fan διατηρείται ο χώρος σε κατάλληλη θερμοκρασία. Όταν το παιδί βγεί από την πόρτα, θα σταματήσει η μουσική, θα σβήσουν τα φώτα και η τουαλέτα θα ξαναγίνει διαθέσιμη.
